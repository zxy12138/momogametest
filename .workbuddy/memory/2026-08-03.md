## 补23：房间布局可视化编辑系统（RoomLayout + RoomLayoutEditor）

### 需求
用户希望「门的位置 / 刷怪点 / 禁区 / 背景对齐」能自己在 Godot 编辑器里**可视化拖拽编辑**，而不是每次让我改代码。经 AskUserQuestion 确认：四类全做，存储用每房一个 `.tres` 资源（非写回 LevelData）。

### 新增文件
- **`src/rooms/DoorDef.gd`**（Resource）：`@export var target: String` + `@export var position: Vector2` —— 单扇门（目标房 + 房间内局部坐标）。
- **`src/rooms/RectDef.gd`**（Resource）：`@export var center: Vector2` + `@export var size: Vector2` —— 矩形禁区。
- **`src/rooms/RoomLayout.gd`**（Resource）：`@export var doors: Array[DoorDef]`、`spawn_points: Array[Vector2]`、`blocked: Array[RectDef]`、`bg_offset: Vector2`、`bg_scale: float`。每房一份。
- **`src/rooms/RoomLayoutEditor.gd`**（@tool Node2D）：按 `floor_idx`+`room_id` 加载该房，显示美术整图背景 + 房间边界(`_draw`)，为每个邻居生成可拖拽 `Marker2D`(门)、显示刷怪点 Marker、禁区 `ColorRect`；`NOTIFICATION_EDITOR_PRE_SAVE` 时把当前位置写回 `res://src/rooms/layouts/{层}_{房}.tres`。
- **`src/rooms/RoomLayoutEditor.tscn`**：上述脚本的根场景（无 uid，交由 Godot 生成）。
- **`src/rooms/layouts/`**：资源目录（已建，初始空，运行期/编辑器按需生成 .tres）。

### 接入 RoomManager.gd
- `setup()` 开头 ` _layout = _load_layout()`；新增 `_load_layout()`（按 `res://src/rooms/layouts/%d_%s.tres` 读取，无则 `RoomLayout.new()` 退化）。
- `_build_doors()`：用 `_layout.doors` 的 `target→position` 覆盖默认四边中点（`door_map.get(nid, edges[i])`）。
- `_build_floor()`：末尾应用 `_layout.bg_offset` 与 `_layout.bg_scale`（默认 0/1，等同原行为）。
- `_spawn_content()` + `_next_spawn_pos()`：若 `_layout.spawn_points` 非空则循环使用（替代 `_rand_pos()` 随机散布）。
- 新增 `_build_blocked()`：把 `RectDef` 生成 `StaticBody2D`(collision_layer=16)+`CollisionShape2D` 碰撞 + 半透明红色 `ColorRect` 可视。

### 用户工作流（在编辑器里，无需我再写代码）
1. 打开 `res://src/rooms/RoomLayoutEditor.tscn`
2. Inspector 设 `floor_idx`(1/2/3) 与 `room_id`(如 "r2") → 2D 视口即显示该房整图 + 可拖拽的 Door_*/Spawn_*/Blocked_* 标记
3. 直接拖拽（禁区还可拖角缩放）；背景偏移/缩放在 Inspector 的 `bg_offset`/`bg_scale` 调
4. **Ctrl+S** → 写回 `layouts/{层}_{房}.tres`
5. F5 运行游戏，RoomManager 自动读取生效

### 已知注意点
- RoomLayoutEditor 是 `@tool` 场景，`_rebuild()` 会在编辑器里动态增删子节点；保存场景时会把这些临时标记也序列化进 .tscn（重开时被 _ready 重建覆盖，功能无碍，仅场景文件略臃肿）。
- 背景偏移/缩放在编辑器里看整图对齐；非预制(瓦片)房也会应用，但通常只调 S_00 整图房。
- 沙箱无 Godot 二进制，未实机跑。请用户 F5 + 打开编辑器场景实测拖拽与 Ctrl+S 落盘。

### 补23 修正：floor_idx/room_id 在 Inspector 不显示（已修）
- **真正根因（不是 setter 递归！）**：`_build_doors()` 里 `var pos := edges[i] if i < edges.size() else Vector2.ZERO` —— `edges[i]` 是 Variant，三元另一端 `Vector2.ZERO` 是 Vector2，类型对不上 → GDScript 无法推断 `pos` → **整份脚本 Parse Error 编译失败** → Inspector 该脚本字段全部消失（用户一开始"找不到 floor_idx"就是它，非递归）。
- **修法**：`var edges: Array[Vector2] = [...]` 显式标类型，`var pos: Vector2 = ...` 显式标类型 → 推断歧义消除，脚本恢复编译。
- **顺手加固**：把 `floor_idx`/`room_id` 改成 backing field（`_floor_idx`/`_room_id`）+ `get`/`set`（杜绝潜在的 setter 内 self 赋值递归），并加 `@export_group("房间布局编辑 (Room Layout)")` 让字段在 Inspector 有显眼中文分组。
- 提醒用户：打开 `RoomLayoutEditor.tscn` 后，在 Scene 面板选中根节点 `RoomLayoutEditor`，再到 Inspector 的「房间布局编辑 (Room Layout)」分组里找 `Floor Idx`(默认1) 与 `Room Id`(默认"r1")；改值即视口即时重绘。
