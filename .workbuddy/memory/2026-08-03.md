## 补20：3 层关卡流程重排 + 头尾剧情场景（Prologue / Epilogue）

### 需求
用户给流程图（起点→战斗1→战斗2/3→精英→驿站→Boss），并要求在最开头与最结尾各加一个剧情场景作为「剧情的关卡」。三个对话确认：
1. **Prologue 位置**：Intro 视频后，进入 Game 前
2. **Epilogue 后**：继续呆在关卡里面，出现提示词，ESC 退出
3. **现有 `_play_prologue`**：保留，剧情与游戏内独白并存

### 改动
- **`src/data/LevelData.gd`**：3 层同步把 `r4`(inn) ↔ `r5`(elite) 互换 type 与 enemies。pos 与 neighbors 不动。
  - 旧：`r1 → r2/r3 → r4(inn) → r5(elite) → r6(boss)`
  - 新：`r1 → r2/r3 → r4(elite) → r5(inn) → r6(boss)`
- **`src/scenes/Prologue.gd/.tscn`**：第一章「醒来」剧情场景（深底+标题+多行文字+「按任意键继续」）。任意键/鼠标推进或 ESC 跳过。
- **`src/scenes/Epilogue.gd/.tscn`**：终章「黎明」剧情场景，结构同 Prologue。
- **`src/autoload/GameManager.gd`**：加 `var game_completed := false`（一次性瞬态标志，不入存档）。
- **`src/scenes/Intro.gd`**：`NEXT_SCENE` 改 `Prologue.tscn`（原 `Game.tscn`）。
- **`src/scenes/Game.gd`**：
  - 新增 `const EPILOGUE = preload("res://src/scenes/Epilogue.tscn")`、`_completed_state_active`、`_completion_overlay` 字段
  - `_ready` 开头：先查 `game_completed` → 若 true 走 `_enter_completed_state()` 并 return，**优先**于 `prologue_pending` 与 `transition_to("r1")`
  - `on_boss_defeated` 第 3 层：`_birthday()` 改 `_goto_epilogue()`（设 `game_completed=true` + 0.8s 淡出 + 切到 Epilogue）
  - 新增 `_goto_epilogue()` / `_enter_completed_state()` / `_show_completion_overlay()`：回 r6 + 兜底 `boss_cleared[3]=true` + 0.7s 后面板
  - `_unhandled_input`：通关状态下 ESC 直接 `_return_menu()`，不开暂停菜单
  - `_return_menu`：清理 `_completed_state_active`

### 关键设计点
- **Prologue 在 Intro 后、Game 前**：复用 Intro 的 Control+ColorRect+Label 模板，无外部资源
- **通关状态回关卡而非跳出生日**：把原 `_birthday()` 替换为「Epilogue → 回 Game（r6+Boss 房无怪）+ 通关覆盖层 + ESC 主菜单」三段式
- **game_completed 不入存档**：与 `prologue_pending` 同理，是瞬态消费型标志；`Game._ready` 消费后清零，避免污染 SaveManager
- **保留 `_play_prologue`**：用户要求并存——Prologue 是章节全局剧情，`_play_prologue` 是醒来独白，互不冲突
- **r4/r5 neighbors 原本就是 r2/r3↔r4↔r5↔r6 链式结构**：互换 type 后连通路径完全保留，无需改 MapData

### 验证
- 无头 `--scene Game.tscn` 30 帧：EXIT=0，无 SCRIPT/Parse/Invalid
- 无头 `--scene Prologue.tscn` / `Epilogue.tscn`：EXIT=0
- 无头 `--editor`：EXIT=0，文件扫描正常
- LevelData 三层 18 条房间记录手工对照全部正确

### 已知坑
- 暂时未做从通关状态回关卡时的「子弹/敌人清理」检查：进 r6 时 Boss 已死，房间本来就空，玩家可以自由走动；理论上不应残留任何敌人
- 如果用户从通关状态回主菜单再点「继续」读档：SaveManager 不会存 `game_completed`（瞬态），所以读档后正常进入 `layer_index=3` 的 r1 起点房，不会再触发通关覆盖层

### 视觉/手感
- Prologue/Epilogue 的「按任意键继续」提示有 0.3s 延迟淡入，避免一进画面就压过来
- 通关覆盖层居中 480×200，「✦ 恭喜通关 ✦」金色 + 「噩梦已被驱散」蓝白 + 「按 ESC 返回主菜单」白
