## 补24：RoomLayoutEditor 门无法拖拽 + 出生点不可见（已修）
- **门拖不动根因**：原门用 `Marker2D` 且代码 `add_child` 时**未设 `owner`**。Godot 4 中 `@tool` 动态生成的节点若无 `owner = get_tree().edited_scene_root`，2D 视口不把它当可编辑对象 → 点不中、拖不动（仅 Scene 树可选，且 Marker2D 十字准星极难点中）。
- **修法**：`RoomLayoutEditor.gd` 改版：
  - 所有手柄改用 **`Node2D` + 实心 `Polygon2D` 菱形/方块**（一大块好点中），并在 `_set_owner()` 里设 `owner = edited_scene_root` → 视口可点选拖拽。
  - 门=绿色菱形（带「门→rid」标签）、出生点=黄色菱形、禁区=红色半透明方块。
  - 新增 `@export spawn_count` / `blocked_count`：Inspector 调大即生成对应数量可拖手柄（保留已有拖拽位置），Ctrl+S 写回 `.tres`。解决「出生点看不到」——此前仅当 `.tres` 已含 spawn_points 才显，新房间默认为空。
  - `_save_layout` 门改为按手柄 `get_meta("target")` 重建（不再依赖索引对齐，避免邻居顺序错位）。
- **验证（沙箱无 Godot 二进制，待用户实机）**：重开 Godot → 打开 `RoomLayoutEditor.tscn` → 设 Floor Idx=1 / Room Id="r2" → 应看到绿色门菱形且**可在视口直接拖**；把 Spawn Count 调到 3 → 出现 3 个黄色菱形，拖到刷怪位；Ctrl+S → 生成 `src/rooms/layouts/1_r2.tres`；F5 运行 RoomManager 读取生效（门位/刷怪点/禁区）。
- **已知**：手柄会随场景保存临时进 `RoomLayoutEditor.tscn`（仅臃肿，无害）；重开场景 `_rebuild` 清空并按 `.tres` 重建，数据不丢。

## 复用经验（@tool 可视化编辑器「可拖拽手柄」模式）
- Godot 4 `@tool` 场景里，用代码 `add_child` 的节点要能在 2D 视口被点选/拖拽，**必须** `node.owner = get_tree().edited_scene_root`，且优先用 `Polygon2D`/`Sprite2D` 这类有可见几何的节点，而**不要用 `Marker2D`**（十字准星难点中且易误判为不可拖）。

## 补28：修复 f1-r1 动态 ogv 背景「不播放/仍是静态图」
- **现象**：用户 F5 进游戏，f1-r1 背景是静态图、视频不动。
- **真凶（非导入问题）**：旧 `tile_path()` 先扫 `assets/tiles/` 找到 `S_001_1.png` 就 return，永远轮不到 `Maps/` 里的 `S_001_1.ogv` → 一直加载静态 PNG。

## 补29：修复「全黑屏」— VideoStreamPlayer 播放时序 + @tool 预览调 MapData 崩溃
- **现象**：F5 进 f1-r1 背景全黑；报错 `Game.gd:103 MapData.load_layer placeholder instance` + `video_stream_player.cpp:336 !is_inside_tree`。
- **黑屏主因**：`RoomManager._add_video_floor()` 在 `add_child(vp)` **之前**调 `vp.play()` → `!is_inside_tree`、视频不播，而 `Floor`(TextureRect) 已 `visible=false` → 黑屏。
  - 修：`add_child(vp)` 后 `vp.call_deferred("play")`（保证整棵树就绪后下一帧开播）。
- **@tool 预览崩溃**：`Game._editor_build_preview()` 在编辑器预览期直接调 autoload `MapData` → 该期 autoload 是 placeholder 实例→崩。改用 `LevelData`(class_name 全局类) 取数据并手动注入 `scene_img`；连带改 `RoomManager._room_label()`（setup 内被 `_build_doors` 调用）同样改从 `LevelData.get_layer(_layer)` 取类型。运行期 `transition_to` 仍用 `MapData`(正常加载)。
- **验证**：`RoomManager.gd` 已无 `MapData` 实际调用(仅注释)；`Game.tscn` 无头 EXIT=0 零报错。编辑器预览真渲染视频需用户实机确认。
- **验证（无头完整通过）**：`ResourceLoader.exists(S_001_1.ogv)=true`、`load() is VideoStream=true`；`Game.tscn` EXIT=0 零报错；临时 autoload 确认房间树生成 `FloorVideo`(`class=VideoStreamPlayer, stream=true`)。
- **结论**：用户重 F5 即可见 f1-r1 动态背景（10s 循环静音）。其他房无 ogv 仍显示 PNG。换其他房视频：按 `S_00{层}_{房}.ogv` 命名丢 `assets/tiles/` 或 `assets/tiles/Maps/` 即自动启用。

## 补30：RoomLayoutEditor 动态背景不显示修复（视频/图片统一兼容）
- **现象**：在 `RoomLayoutEditor.tscn` 设 floor_idx=1 / room_id=r1，背景空白，看不到动态地图，没法对着画面摆怪。
