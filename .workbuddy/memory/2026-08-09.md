## 撤销管理器 API 四次踩坑（最终定案：Godot 4.7 = EditorPlugin.get_undo_redo() 返回 EditorUndoRedoManager）
- **第一次**：`EditorInterface.get_undo_redo()` → "Static function not found"（EditorInterface 没有该方法）。
- **第二次**：`EditorUndoRedoManager.create_action()` 静态调用 → "non-static function"（不是自动单例）。
- **第三次**：`EditorPlugin.get_undo_redo_manager()` → "Nonexistent function"（该方法不存在；**注意 get_undo_redo_manager 与 get_undo_redo 是不同方法**）。
- **第四次**：`var ur: UndoRedo = _plugin.get_undo_redo()` → "Cannot assign EditorUndoRedoManager to ur with type UndoRedo"（**get_undo_redo() 返回的是 EditorUndoRedoManager，不是 UndoRedo**；我当时错误判断"4.4+ 移除 EditorUndoRedoManager"——官方文档证明它一直存在）。
- **最终正确方案**（已查证 Godot 4.5/4.7 官方文档）：`var ur: EditorUndoRedoManager = _plugin.get_undo_redo()`，且 **EditorUndoRedoManager.add_do_method(object: Object, method: StringName, ...) 用 object+方法名（不是 Callable）**：`ur.add_do_method(self, "_attach_imported_nodes", nodes)`。
- **其他工具脚本获取方式**：`Engine.get_singleton("EditorInterface").get_editor_undo_redo()`（2025-10 论坛验证）。
- **教训：① 撤销栈 API 版本差异大，先查官方文档再写；② 报错信息混合新旧版本=陈旧 .godot 缓存，改完脚本必须删 .godot 重开**。

## 修复·2026-08-09（f1_r2 解析错误 + 出生"在中心"真根因）
- **f1_r2 解析错误**：rollback_last.py 删 ext_resource 行但没删干净节点块（Light_A/B/C/Spawn 有 unique_id，正则没匹配）→ 节点引用不存在的 `mask_1`/`lflk_1`/`7_spawn_1` → 解析崩溃。修复：截断 f1_r2 尾部残留节点块（Light_A 到 Spawn），剩 47 节点 + 5 ext_resource，所有 ExtResource 引用都有定义。
- **出生"在中心"真根因（终于找到了）**：`Game._swap` 门查找 `entry_door_position(prev_rid)` 的 **rid 跨层撞名**——用户从 f1_r1（rid="r1"）跳 f3_r0 时，prev_rid="r1"，而 f3_r0 恰好有 `Door_r1`（target="r1" 指向层3的 r1 房）→ `entry_door_position("r1")` 匹配上 → 返回门位置 (96,-21) → 玩家出生在 f3_r0 的门（房间上半部偏右 → 屏幕中央偏右）→ 用户感觉"在中间"。**从 f2_r7 跳正常**是因 prev_rid="r7"，f3_r0 无 target="r7" 的门 → 才走 safe_spawn_position。
- **修复**：`Game.gd` 加 `var _crossed_layer := false`——`_switch_floor`/`_go_next_layer`/`_enter_completed_state` 置 true；`_swap` 门查找加 `not _crossed_layer` 守卫 + 消费。跨层跳转（地图/传送门/通关回）不再用 prev_rid 查门（rid 撞名误匹配本层同名门）；同层过门不受影响（_crossed_layer=false 正常查门）。
- **教训**：**rid 在各层重复**（f1_r1/f2_r1/f3_r1 都叫 "r1"）——任何用 prev_rid 匹配门/逻辑的判断，跨层时都会撞名误匹配，必须加跨层标志区分。这是本次"在中心"问题的真正根源。
