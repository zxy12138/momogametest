## 修复：Trying to assign "Array" to "Array[Dictionary]"（严格模式类型不匹配）
- **根因**：`GalgameDialog.play(lines: Array)` 与 `Game.gd._create_galgame_dialog(lines: Array)` 参数是**未类型化 Array**，第 119 行 `_lines = lines` 赋给 `_lines: Array[Dictionary]` → 严格模式编译报错。
- **修复**：两处签名改 `Array[Dictionary]`（`play` + `_create_galgame_dialog`）。调用处全是字典字面量 `[{...}]`，编译器按目标类型推断，无问题。
- **教训**：类型化数组变量（Array[Dictionary]）的赋值/传参链路必须全程类型化；函数签名参数不要用裸 `Array` 接收后赋给类型化数组。

## 修复：Galgame 对话框完全不显示（3 个布局 bug + 触发链路确认）
- **根因（确定性 bug ×3）**：
  1. **立绘槽宽度为负**：`_portrait_left.set_anchors_preset(BOTTOM_LEFT)` 后只设 `offset_left=40`，`offset_right` 默认 0 → 宽 = 0-40 = **-40px 负宽，Control 不渲染**（左右立绘都消失）。修复：双边 offset（left=40/right=270 → 宽 230；top=-600/bottom=-200 → 高 400）。右槽同理（left=-270/right=-40）。
  2. **名字框在屏幕外**：`_name_label.position = Vector2(56, -184)` 绝对坐标 y=-184 在视口上方之外。改 BOTTOM_LEFT 锚点 + 双边 offset。
  3. **`_build_ui` 放 `_init`**：节点无父无 rect 时锚点预设不可靠。移到 `_ready`（进树后执行）；`play()` 加 `_text_label==null` 防御补构建。
- **触发链路确认**：Main 新游戏 → `prologue_pending=true` → Game._ready → `_play_prologue` → `_create_galgame_dialog` → `dlg.play`。**注意：F6 直接跑 Game.tscn / 「继续」/ 死亡重开 都不会触发开场对话（prologue_pending=false）**——若测试时看不到对话请从主菜单新游戏进入。
- **防御**：`_end_prologue` 补 `_galgame_active=false`（ESC 跳过路径 queue_free 不触发 finished 回调，需手动清标志）。
- **调试**：`_play_prologue`/`_create_galgame_dialog` 加 `print("[GALGAME] ...")`，运行看 Output 面板确认触发与句数。
- **教训**：Control 用 `set_anchors_preset` 后必须给左右/上下双边 offset（单边会算负宽不渲染）；UI 构建放 `_ready` 不放 `_init`。
