## 武器跟随鼠标旋转偏移修复（16:41 用户反馈）
- **现象**：武器"没对准鼠标"——鼠标在角色下方时武器不在正下方，有偏移。
- **排查**：
  1. 数学验证：`aim.angle()` + `(cos,sin)*R` 四方向(0,±1)/(±1,0)全部精确（探针 6/6）→ 轴心/坐标/旋转公式本身对
  2. 相机：`canvas_transform = Transform2D(Vector2(z,0), Vector2(0,z), center-focus*z)` → `get_global_mouse_position()` 正确转世界坐标
  3. **真根因①（位置偏移）**：`_lunge = aim*18` 攻击时设置、每帧只 lerp(0.3) 衰减 → **持续攻击时 _lunge 不断刷新，武器位置永远偏 18px**（正下方时武器在 (0,46+18)=(0,64)），看起来"没对准"
  4. **真根因②（视觉偏）**：武器贴图内容非对称（sword 左:右=15198:12143 重心偏左），centered 旋转后内容中心不在轴线上 → 尖端视觉不指鼠标
- **修复（WeaponSystem.gd）**：
  1. `_update_orbit` 稳态分支（非挥砍）`sp.position = (cos,sin)*46` **去掉 +_lunge**；`_lunge` 只叠加在挥砍分支（冲刺感）
  2. `_lunge.lerp(ZERO, 0.3)` → **0.5**（攻击后更快归零）
  3. 新增 `_calc_content_offset(tex)`：`get_used_rect()` 内容中心 → 贴图中心偏移，存 `_content_offsets`，`_update_orbit` 里 `sp.offset = _content_offsets[i]` → 内容中心落在角色→鼠标轴线，尖端朝鼠标（sword 实测 offset (-8.5,-8.0)）
  4. `_rebuild_orbit`/`replace_active` 换贴图时重算 offset
- **坑**：`get_used_rect()` 返回 Vector2i，`bbox.position + bbox.size*0.5` 报 "Invalid operands Vector2i and Vector2" → 需 `Vector2(bbox.position)` 显式转
- **验证**：编译零错误；四方向数学探针 6/6；内容偏移计算正确（sword -8.5,-8.0 / staff -2.5,0.5）
- **教训**：武器轨道类功能——"稳态必须干净"（攻击冲刺偏移绝不能在稳态残留）；贴图内容非对称要用内容中心补偿而不是裸 centered 旋转。
