## 15:18 体型/碰撞调节改为「全局类型级」（应用到所有同类型怪）+ Boss 加碰撞

用户反馈：之前做的"选中单个手柄调大小"不符合需求，要的是**按类型全局调**——在插件里切换小怪/Boss 类型，滑块调到某个值后，场景里所有该类型的怪都生效（例：调闹钟怪 → 所有闹钟怪都变大），且 Boss 也要能调碰撞范围。

### 实现
1. **新增 `src/data/ScaleConfig.gd`**（class_name 全局类，无 autoload，编辑器插件+运行期 RoomManager 都能用）：
   - 数据存 `res://src/data/enemy_scale.json`，结构 `{enemies:{id:{scale,collision}}, bosses:{id:{scale,collision}}}`
   - 静态方法 `get/set_enemy_scale`、`get/set_enemy_collision`、`get/set_boss_scale`、`get/set_boss_collision`；每次读写直接读文件（无缓存），编辑器改完即时生效
   - **踩坑**：`_get`/`_set` 是 Object 内置虚函数签名（`_get(StringName)->Variant`），静态函数同名会报 "function signature doesn't match the parent"。改名为 `_get_val`/`_set_val`。
2. **Boss.gd 加碰撞范围**：新增 `_boss_collision_mult` + 覆盖 `set_collision_mult`；`_apply_form_cb` 里碰撞框 sc = form scale × `_boss_scale_mult` × `_boss_collision_mult`（sprite 视觉只乘 scale，不含 collision）。
3. **RoomManager 应用全局缩放**：`_spawn_enemy` 最终 `set_scale_mult(全局scale×逐实例scale)`、`set_collision_mult(全局collision×逐实例collision)`；`_spawn_boss` 同理 `set_scale_mult(全局scale×逐实例)`、`set_collision_mult(全局collision)`。逐实例 handle 的 scale_mult/collision_mult 仍保留作微调（默认 1.0 不影响）。
4. **RoomDockPanel 改成全局类型级 UI**：替换掉上一轮的"选中手柄显示滑块"（逐实例），改为固定区块：
   - 「目标」OptionButton（小怪/Boss）
   - 「类型」OptionButton（按目标填充 EnemyHandle.IDS / BossHandle.BIDS，显示中文名+id）
   - 「体型」HSlider 0.1~3.0 + 「碰撞」HSlider 0.1~3.0
   - 切换目标/类型 → `_refresh_adj_sliders` 把滑块同步到该类型全局值；拖滑块 → 写回 ScaleConfig（`_adj_syncing` 标志防同步时反向写回）。

## 15:51 修复：开场动画未铺满全屏 + 体型/碰撞调节在编辑器中不实时显示

用户反馈两点：(1) 开头动画是 720p 没有放大到整个屏幕；(2) 在插件面板调整大小和碰撞后，.tscn 场景里看不到实时变化。

### 问题1 根因与修复（Intro.tscn）
- **根因**：`VideoStreamPlayer` 之前设的是 `stretch_mode = 2`，但 Godot 4.7 已**没有 stretch_mode 枚举**（之前踩坑记过：4.7 用 `expand=true` 而非 stretch_mode）。`expand` 没设 → 视频按 720p 原生尺寸居中显示，不铺满。窗口是 1920×1080（16:9），视频 1280×720 也是 16:9，设 `expand=true` 即等比铺满全屏、无变形。
- **修复**：`src/scenes/Intro.tscn` 把 `stretch_mode = 2` 替换为 `expand = true`。
- **验证**：`--headless --script` 加载 Intro.tscn，确认 `expand` 属性存在=true 且 `stretch_mode` 已从节点消失（印证 4.7 无此属性）。

### 问题2 根因与修复（编辑器实时预览）
- **根因**：插件滑块只写全局 `ScaleConfig`(JSON)，但编辑器里的 `EnemyHandle`/`BossHandle` 预览 `_redraw` **只读了逐实例的 scale_mult/collision_mult，完全没读 ScaleConfig**；且滑块改动后也**没有触发手柄重绘**。运行期 RoomManager 是对的（已读 ScaleConfig），只有编辑器预览缺这环 → 拖滑块场景不变。
- **修复**：
  1. `EnemyHandle._redraw` / `BossHandle._redraw` 读取 `ScaleConfig.get_enemy_scale/collision(id)`、`get_boss_scale/collision(bid)`，与运行期 RoomManager 一致（最终=全局×逐实例），碰撞框尺寸=体型×碰撞倍率同步缩放。
  2. `RoomDockPanel` 新增 `_redraw_handles_of_type(id, is_boss)`（递归查找当前编辑场景里同类型手柄并 `call("_redraw")`），在两个滑块回调 `_on_adj_scale_changed`/`_on_adj_coll_changed` 写回 ScaleConfig 后立即调用 → 拖动滑块场景里该类型所有怪实时变大/碰撞框实时变化。
- **验证**：headless 编译零错误；ScaleConfig 全局读取正常（alarm_clock 已存 scale=0.45/coll=0.65，手柄现能读到）。
- **改动**：`src/scenes/Intro.tscn`、`src/rooms/handles/EnemyHandle.gd`、`src/rooms/handles/BossHandle.gd`、`addons/room_layout_dock/RoomDockPanel.gd`。
