1.1 游戏核心循环
选择武器 → 进入梦境地图（网状房间结构）→ 自由探索房间 → 消灭噩梦怪物
离开房间后怪物刷新，可反复刷取经验和梦晶
积累经验升级 → 挑战精英 → 挑战Boss → 净化该层梦境
通关后网状地图所有已解锁房间保持可传送，继续刷到 Lv.30
1.2 故事背景
在这座城市里，有一个人。他每天早上 9 点打卡，每天晚上 11 点下班，周末接受「弹性调休」。白天他麻木地盯着电脑，晚上他连做梦都做不好——那些梦里全是 KPI、全是 DDL、全是在电梯里上不去的楼层。
弥绘察觉到了这个被噩梦侵占的意识。那里的黑暗不是妖怪，是疲惫；不是魔法，是压力；不是恶龙，是那个永远打不完的周报。
「没关系，」弥绘跃入梦境，「噩梦嘛，交给我。」
——她是食梦貘，消灭噩梦是她的天职，也是她的生日许愿。

四、地图系统（网状房间地图）
4.1 地图结构概念
每一层梦境由若干小房间组成，房间之间通过走廊/门连接，形成不规则的网状结构（非线性路线）。玩家在层内自由穿行，地图界面在任意时刻可以打开查看。

4.3 网状地图 Godot 实现建议
用 Node2D + 自定义脚本绘制房间节点和连线
每个房间节点存储状态枚举：LOCKED / VISITED / CURRENT / BOSS_CLEARED
解锁逻辑：玩家进入某房间时，该房间状态变为 VISITED，并解锁其相邻房间的显示（但不解锁传送）
传送逻辑：点击已访问房间节点 → 弹出确认框 → 淡出 → 切换到目标房间场景 → 淡入
地图数据用 Dictionary 存储：room_id → {type, state, connections[]}，通过 GameManager 全局访问
地图 UI 建议独立 CanvasLayer，快捷键 M 或 Tab 切换显示/隐藏
4.4 房间内怪物刷新机制（魂类机制）
每个房间在玩家「离开」时启动刷新计时器（立即重置，无需等待）
玩家返回该房间时，所有普通怪物重新生成，精英怪以 60 秒为周期刷新一次
Boss 房间：Boss 击败后永久清除，但 Boss 房间内的小怪（若有）正常刷新
刷新的怪物经验值为原来的 100%（无削减），梦晶掉落正常，鼓励反复刷图升级
Godot 实现：RoomManager.gd 监听 Area2D 的 body_exited 信号，离开后调用 spawn_enemies()

七、关卡详细规划（社畜梦境版）
7.1 世界观总纲：现代社畜的噩梦
梦主是一名普通的当代打工人。白天他西装革履，彬彬有礼；晚上他的梦境里充满了加班、被催 KPI、永远发不出去的邮件、开不完的会。
弥绘潜入的不是魔幻世界，而是一个被现实焦虑扭曲的「职场梦境」。场景写实但细节荒诞：电梯永远停在「老板楼层」，会议室里的PPT自己动起来了，下班的路会无限循环……
怪物的设计原则：「职场压力具象化」——它们看起来像真实存在的东西，但被噩梦扭曲成了怪物。

9.2 暴击代码示意（WeaponBase.gd）
func deal_damage(target):
    var base_dmg = weapon_damage * owner.attack_multiplier
    var is_crit = randf() < owner.crit_rate
    var final_dmg = base_dmg + (150 if is_crit else 0)
    target.take_damage(final_dmg)
    if is_crit:
        spawn_crit_number(final_dmg)  # 弹出橙色暴击数字
        get_tree().get_first_node_in_group("camera").shake(0.1, 3)
