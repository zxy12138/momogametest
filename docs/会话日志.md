## 2026-08-11 16:41 · 武器跟随鼠标旋转偏移修复

**需求**（用户 4 点）：
1. 武器以角色中心为旋转轴心（而非鼠标）
2. 尖端准确指向鼠标，四方向（上/下/左/右）精确对齐
3. 检查坐标转换，统一参考系
4. 提供可复用修复代码 + 说明原因

**诊断过程**：
1. **数学验证**（探针 6/6）：`aim.angle()` + `(cos,sin)*46` 在四方向 (0,1)/(1,0)/(0,-1)/(-1,0) 及斜角全部精确 → 轴心/坐标/旋转公式本身正确
2. **相机验证**：Game.gd `canvas_transform = Transform2D(Vector2(z,0), Vector2(0,z), center-focus*z)`，`get_global_mouse_position()` 正确转世界坐标 → 瞄准坐标系统一（世界方向 = 局部方向，Godot 2D 无旋转场景成立）
3. **真根因①（位置偏移）**：`_lunge = aim*18` 在 `_attack()` 设置，`_update_orbit` 里**稳态也叠加 `+ _lunge`**，而 `_lunge.lerp(ZERO, 0.3)` 每帧仅 30% 衰减——**持续攻击时 _lunge 不断被刷新，武器位置永远偏 18px**（正下方时武器在 (0, 46+18)=(0,64)，用户看到的"没对准"）
4. **真根因②（视觉偏）**：武器贴图内容非对称（如 sword 重心左偏 15198:12143），`Sprite2D centered` 旋转时内容中心不在角色→鼠标轴线上 → 尖端视觉上不指向鼠标

**修复（`src/weapons/WeaponSystem.gd`）**：
1. 稳态分支（非挥砍）`sp.position = Vector2(cos, sin) * 46.0` **去掉 `+ _lunge`**——`_lunge` 只保留在挥砍分支（攻击瞬间的冲刺感）
2. `_lunge.lerp(ZERO, 0.3)` → `0.5`（攻击后更快归零，减少残留窗口）
3. 新增 `_calc_content_offset(tex)`：用 `get_used_rect()` 求贴图内容中心 → 贴图中心偏移，存 `_content_offsets`；`_update_orbit` 里 `sp.offset = _content_offsets[i]`——武器旋转后**内容中心落在角色→鼠标轴线上**，尖端精确朝鼠标
4. `_rebuild_orbit` / `replace_active`（换武器贴图）时重算 content offset
5. **坐标轴心确认**：Weapon 节点是 Player 子节点 position=(0,0)（角色中心为轴），已加注释说明

**验证**：
- Godot 全量编译零错误
- 四方向轨道数学探针 6/6 精确
- 内容偏移计算正确：sword offset (-8.5,-8.0)、staff offset (-2.5,0.5)

**踩坑**：`get_used_rect()` 返回 Vector2i，`bbox.position + bbox.size * 0.5` 报 `Invalid operands "Vector2i" and "Vector2"` → 需 `Vector2(bbox.position)` 显式转换。

**可复用要点**（给用户的方案说明）：
- 旋转轴心 = 武器节点的父节点（角色）原点：`sp.position` 用局部坐标 = 绕角色转
- 方向 = 世界坐标差归一化 `(mouse_global - player_global).normalized()`，`rotation = aim.angle()`（贴图 +X 为尖端）
- 稳态与瞬态分离：冲刺/后坐偏移只在攻击瞬间叠加，稳态必须干净
- 内容非对称补偿：`sp.offset = 贴图中心 - 内容中心`
