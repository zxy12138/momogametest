## 一、怪物体系总览

游戏共 **16 种小怪（含精英）+ 3 个 Boss**，按三层主题划分。

| 层 | 主题 | 普通怪 | 精英 |
|---|---|---|---|
| 第一层 | 午夜办公室 | 闹钟怪物、路灯怪、小狗怪、除草工人 | 马路撒手 |
| 第二层 | 无尽通勤路 | 透明上班族、蜘蛛怪、催眠电视、僵尸上班族 | 蜈蚣怪 |
| 第三层 | 深夜崩溃核心 | 加班工作者1、kpi团、打印机怪、加班工作者2、加班工作者3 | 硬件核心 |

Boss（按层）：梦魇公车（公交→机器人）/ 昆虫僵尸（僵尸→完全昆虫）/ 加班电脑老板（人形→电脑机），全部双形态（详见第五章）。

### 1.1 五种行为类型（攻击方式总纲）

所有怪物按 `behavior` 字段分六类：

| 行为 | 移动逻辑 | 攻击方式 | 判定伤害 |
|---|---|---|---|
| **chase**（近战·追击） | 直线追向玩家，永远贴身 | 近身碰撞（Hitbox 触体即伤） | `contact_dmg` |
| **charger**（近战·冲锋） | 直线追向玩家，速度极高 | 近身碰撞；部分怪撞击时带范围溅射 | `contact_dmg`（+`aoe_on_hit`） |
| **shooter**（远程·弹幕） | 保持在 `atk_range` 距离（85% 外追、40% 内退、中间停） | 按 `atk_cd` 周期发射 1~N 发弹幕（可散射/追踪） | `proj_dmg`（弹幕命中） |
| **aoe**（范围·脉冲） | 接近到 `aoe_radius` 停下 | 按 `atk_cd` 周期原地脉冲（冲击波特效），圈内直接伤害 | `proj_dmg`（圈内） |
| **patrol**（锁定追击·近战） | 始终直线锁定玩家追击（不脱离）；移动动画按追击方向切换（下/右/上/左） | 近身（`atk_range` 内）按 `atk_cd` 周期近战攻击（attack 动画 + 接触碰撞） | `contact_dmg` |
| **hybrid**（近战+远程混合） | 远距（`hybrid_range` 外）保持距离射击；近身切换追击 | 远程按 `atk_cd` 弹幕（attack 动画）；近身（`melee_range` 内）按 `melee_cd` 近战（melee 动画 + 接触碰撞） | `proj_dmg` + `contact_dmg` |

通用机制：
- 怪物被冰冻/减速/麻痹时移动速度按倍率降低（冰冻 0.15× / 减速 0.5× / 麻痹 0）。
- 死亡掉落 XP（`Pickup` 拾取物），Boss 额外掉落梦晶 ×5（20 梦晶/个）。
- 普通怪精灵规格 **130×250**（旧体系）/ **128×128**（新 16 怪多行精灵表），Boss **260×500**。
- **新体系约定**：所有小怪支持动画键 `walk_down`/`walk_right`/`walk_up`/`walk_left`/`attack`/`attack_left`/`dead`/`dead_left`（混合怪另有 `melee`/`melee_left`），按精灵表行序 + 镜像生成；`Enemy.gd` 用 `anim_frame_key` 映射帧数字段，无 idle 兜底播第一个动画。
- **动画方向性**：攻击/死亡/近战动作有方向，向右主键 + 镜像生成 `*_left`（朝左攻击/死亡播镜像版，不再靠 flip_h 翻转动作，避免动作方向奇怪）。
- **多行动画表**：1024×1024 素材按行/列切条；行序即行为。**2026-08-15 全部 16 怪已切片为完整动画**（含 walk/attack/dead/melee 的 left 镜像 + 各自弹道贴图），无立绘占位。

### 1.2 状态与通用数值

- 接触伤害（`contact_dmg`）：chase/charger/patrol 贴近时每秒触发（Hitbox body_entered）。
- 弹幕伤害（`proj_dmg`）：shooter 的弹射物命中伤害；aoe 的脉冲圈内伤害。
- `knockback`：部分怪带击退（当前玩家侧击退未实装，仅直接伤害）。
- `is_elite`：精英怪标识（高 HP、高伤害、高奖励）。
- Boss 虚弱窗口（最终 Boss）：阶段切换时 2.5s 内受伤害翻倍 + 强制暴击。

### 2.1 工具链

| 环节 | 推荐工具 | 说明 |

| 精灵表处理 | **`tools/slice_enemy_rows.py`**（项目内，主力） | 按行序表切片（alpha>60 行检测 + 固定 8×128 网格），自动镜像 walk_left、导出弹道贴图 |

## 五、Boss 图鉴（2026-08-16 全新双形态体系）

> Boss 通用机制（`Boss.gd` 双形态架构）：
> - **两形态**：形态1（form1）血量打空 → 播放**变身动画**（Anime 大图切帧，Boss 本体身上播，期间无敌定身）→ 形态2（form2）满血接管 → 打死形态2 才通关。
> - **血量分配**：form1 血量（打空即变身）+ form2 血量（满血）。变身动画播完自动切形态2（换 SpriteFrames + 行为 + 碰撞框 + 血量回满）。
> - **行为**（`_tick_form_behavior`）：`charger` 公交形态（追击+周期冲撞+近身触手）/ `patrol` 人形态（锁定追击+近身拍巴掌）/ `hybrid` 混合形态（远距弹幕+近身近战，昆虫僵尸·完全昆虫·机器人·电脑机）。
> - **移动**：素材仅 down/up/right 三向，向左用 `walk_left` 镜像（flip_h 兼容）。
> - **弹道**：远程形态自带 `{fid}_proj.png` 弹道贴图；铁块/光弹多帧弹道**每次发射随机取 1 帧**（`proj_random=true`）。
> - **素材源**：`assets/sprites/bosses/{layer}/F{x}_B_{NNN}.png` 多行动画表 + `F{x}_B_00{1}Anime.json/.png` 变身动画（1280×720/帧），由 `tools/slice_boss.py` 切片（帧格 192，`{fid}_transform.png` 变身条）。

- **形态2 · 机器人型**（F1_B_002）：行为 `hybrid` —— 远程**发射铁块**（弹道 2 帧随机选 1）+ 近身**手下砸**（melee 8帧）。素材行序：下8 / 上8 / 右8 / 死8 / 铁块8 / 下砸8 / 待机8 / 弹道2。
