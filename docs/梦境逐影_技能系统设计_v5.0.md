> 状态：设计定稿（2026-08-11）。替代旧「终极技能·噩梦吞噬」每房一次的设计。
> 三步流程：设计 → 本文档 → 代码实现（GameManager/HUD/Weapons/Player/WeaponSystem）。

## 一、蓝条（法力）机制

### 1.1 基础数值

| 项 | 数值 | 说明 |
|---|---|---|
| 最大法力 `max_mana` | **100** | 全局常量，开局/死亡重置时回满 |
| 初始法力 `mana` | **100**（满） | 开局即可放技能 |
| 自动恢复 `mana_regen` | **8 点/秒** | 恒定恢复（含战斗），从空回满 ≈ **12.5 秒** |
| 技能消耗 | **100（全部）** | 任意武器技能释放后蓝条清零 |
| 恢复条件 | 无额外条件 | 恒定恢复，不因受伤/位移中断（简化且可预期） |

### 1.2 设计理由
- **全蓝消耗 + 8/s 恢复**：把"冷却时间"抽象成蓝条，技能节奏完全可视化——玩家看到蓝条满就知道可以放。
- **12.5s 周期**与普通攻击 CD（0.3~0.85s）拉开 15~40 倍差距，保证技能是"大杀器"而非"连发普攻"。
- 蓝条放在血条正下方（视觉同源），不额外占屏。

### 1.3 UI 布局（HUD 调整）
```
血条   (16, 14)  220×16  红
蓝条   (16, 32)  220×10  蓝 ← 新增
经验条 (16, 46)  220×8   紫 ← 下移
文字标签整体下移 6px
```

## 二、武器专属技能（E 键释放）

> 触发键 `ultimate`（E）。原「终极·噩梦吞噬」移除，替换为当前持有武器的专属技能。
> 所有技能消耗全部蓝条，无独立 CD（蓝条即冷却）；释放带 0.5s 输入缓冲防误触。

### 2.1 技能总表（8 把武器，效果互不相同）

| 武器 | 技能名 | 类型 | 效果描述 | 伤害倍率 | 额外机制 |
|---|---|---|---|---|---|
| **staff** 梦幻法杖 | **星尘陨落** | 单体爆发·远程 | 朝鼠标方向连射 **5 发光弹**，弹速 520、穿透 3 | **5 × 12** = 60 | 弹体大号特效 |
| **sword** 星芒短剑 | **剑气纵横** | 单体爆发·近战 | 前方 **200px 长×40px 宽剑气波**，直线穿透所有敌人 | **4 × 15** = 60 | 无视目标数 |
| **scythe** 噩梦镰刀 | **死亡之环** | 范围伤害 | **360° 半径 130px** 环斩，清场 | **4 × 11** = 44/只 | 全周覆盖 |
| **bow** 梦境弓 | **追星箭雨** | 范围伤害·远程 | 前方 **60° 扇形 8 支箭**齐射 | **2.5 × 16 × 8** = 320 总伤 | 贴脸全中 |
| **hammer** 噩梦骨锤 | **大地震裂** | 范围伤害+控制 | 全屏冲击波，命中**击退 150px** | **4 × 24** = 96 | 击退控场 |
| **whip** 暗影长鞭 | **缚梦鞭锁** | 控制 | 前方 **90° 扇形**敌人**定身 2 秒** | **2 × 13** = 26 | 强控制 |
| **spear** 星穿长枪 | **突袭连刺** | 单体爆发+位移 | **向前冲刺 120px**，路径上敌人贯穿 | **3 × 18** = 54 | 位移穿敌 |
| **axe** 旋风飞斧 | **暴风战斧** | 增益+范围 | 自身**攻速 +50%（3s）** + 周围 **100px** AOE | **2.5 × 20** = 50 | 攻速 buff |

### 2.2 差异化设计意图
- **单体爆发**（staff/sword/spear）：打 Boss / 精英，伤害集中。
- **范围伤害**（scythe/bow/hammer）：清杂兵群。
- **控制**（whip/hammer 击退）：逆境保命、打断。
- **增益**（axe）：持续作战/爆发窗口。
- 覆盖「输出 / 范围 / 控制 / 增益」四象限，保证每种武器在特定局面有不可替代性。

## 三、数值平衡

### 3.1 蓝耗与节奏
- 全部技能蓝耗 **100**（一致）→ 公平起跑；技能频率 ≈ 12.5s/次，不依赖武器 CD。
- 输入缓冲 0.5s：防止按住 E 连放时"蓝没满就释放失败"的挫败感。

### 3.2 伤害公式
```
技能总伤害 = 武器基础 dmg × 倍率 × GameManager.attack_mult（随等级成长）
```
- 单体期望：staff 60 / sword 60 / spear 54 → 接近（±10%）
- 范围期望：scythe 44×N / hammer 96 / axe 50 → 靠"目标数"体现上限
- 控制：whip 26 + 2s 定身（功能价值折算 ≈ 40+ 伤害）
- 增益：axe 50 + 3s 攻速（持续收益折算）

### 3.3 成长曲线
| 阶段 | 玩家等级 | attack_mult | 技能基础伤害（staff 例） | 说明 |
|---|---|---|---|---|
| 第 1 层 | 1~8 | 1.0~1.6 | 60~96 | 蓝 12.5s 一管，2 发收杂兵 |
| 第 2 层 | 9~18 | 1.6~2.6 | 96~156 | 技能成为 Boss 战主输出窗口 |
| 第 3 层 | 19~30 | 2.6~4.0 | 156~240 | 配合攻速/暴击词条爆发 |

- 蓝恢复固定 8/s：技能频率恒定 → 成长只靠"伤害量"，数值曲线干净。
- 平衡依据：以 **12.5s 周期内的 DPS** 对齐 8 把武器——单发技能 DPS ≈ 每秒 4.3~7.7（伤害/12.5s），接近各自普攻 DPS 的 3~5 倍，体现"大招"定位又不失控。

### 3.4 调整思路
- 若某武器胜率偏高：砍倍率 0.5、或把特殊机制改成消耗更高（如 axe 攻速 50%→40%）。
- 若蓝条感觉拖节奏：mana_regen 8→10/s（回满 10s）；若太频繁：8→6/s（16.7s）。

## 四、实现映射

| 模块 | 改动 |
|---|---|
| `GameManager.gd` | 加 `max_mana=100 / mana / mana_regen=8` + `_process` 恢复 + `spend_mana()` + `mana_pct()`；重置回满 |
| `HUD.gd` | 血条下加蓝条 ColorRect（(16,32) 220×10 蓝），经验条下移，`_ult` 标签改技能名 |
| `Weapons.gd` | DATA 每武器加 `skill`（name/desc/type/mult） |
| `Player.gd` | `_cast_ult` → `_cast_skill`（读当前武器 skill，E 触发，消耗全蓝，0.5s 缓冲）；`ult_ready` → `skill_ready`（mana≥98） |
| `WeaponSystem.gd` | 加 `_cast_skill(w)` 执行 8 种效果（弹幕/剑气/环斩/箭雨/冲击波/定身/冲刺/增益） |
| `Game.gd:303` | 删 `p.reset_ult()` 每房重置（蓝条自动恢复，无需重置） |
